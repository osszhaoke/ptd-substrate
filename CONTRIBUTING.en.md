# Contributing

[简体中文](CONTRIBUTING.md)


## Before contributing
Use fictional inputs and a new local space. Report the version, steps, expected result and actual result. Keep personal information out of patches. Preserve names and original records in UI translations.

## Verification
Run the explicit release tests in the README. State the platform and unverified conditions. Describe static checks, fictional runs and real acceptance separately. [Report security issues privately](SECURITY.en.md).
