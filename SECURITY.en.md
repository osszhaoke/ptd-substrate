# Security reporting

[简体中文](SECURITY.md)


## Report privately
[Private vulnerability reporting](https://github.com/osszhaoke/ptd-substrate/security/advisories/new) is enabled. Include the version, prerequisites, impact and a minimal fictional reproduction. Keep exploit details out of public issues.

## Protect personal data
Exclude real health data, account information, tokens, keychains, settings files and databases. Relevant areas include instance isolation, access controls, read-only paths, imports and archive integrity. If the private form is unavailable, use [Issues](https://github.com/osszhaoke/ptd-substrate/issues) only to request a private channel. Wait before sending details.
