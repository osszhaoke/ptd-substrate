# Roadmap decisions and open design questions

[Read in Chinese](OPEN_QUESTIONS.md)

## Confirmed decisions

The maintainer confirmed the three groups in the [roadmap](roadmap.en.md), including local encryption in the next version. Signing and notarization are the first priority. For feedback, maintainers will do their best to reply, with no fixed response time. [Feedback guide](feedback.en.md)

## Open design questions

- Local encryption: which databases, originals, indexes, logs and backups will it cover? If people lose access to their Mac keychain, will they be able to recover their data and, if so, how?
- Uninstall: can one entry point simplify removal while still showing which data, settings and credentials the user is about to delete? The current [uninstall guide](uninstall.en.md) provides commands with separate confirmation steps.
