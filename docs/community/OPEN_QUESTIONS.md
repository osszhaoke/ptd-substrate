# 路线图决定与待定设计

[English](OPEN_QUESTIONS.en.md)

## 已确认

维护者已确认[路线图](roadmap.md)的三个档位，包括将本地加密列入下一版。签名与公证排第一。反馈采用“尽力回复”，不承诺固定时限。[反馈指南](feedback.md)

## 待定设计

- 本地加密覆盖哪些数据库、原件、索引、日志和备份？用户失去 Mac 钥匙串访问权后，能否恢复数据、如何恢复？
- 卸载能否简化成一个入口，同时让本人看清将删除的数据、配置和凭据？当前[卸载指南](uninstall.md)提供分项确认的命令。
