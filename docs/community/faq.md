# 伙伴试用常见问题

[English](faq.en.md)

## 校验不一致怎么办？

先停止安装。确认压缩包和外部校验表来自同一版本的 Release，放在同一个下载目录，保留原文件名。运行下面第一条命令。通过后在新的空目录解压，进入解压出的程序目录，运行第二条命令。若重下后仍失败，请反馈失败的文件名和版本。[安装说明](../../AGENT_INSTALL.md) · [校验器](../../scripts/verify_release.py)

```sh
shasum -a 256 -c SHA256SUMS
```

```sh
sh scripts/verify_release.sh
```

## 我的 Python 版本可以用吗？

本版演练使用 Apple 芯片、macOS 27.0.1 和 Python 3.14.8。先查看本机环境，再确认同一 Python 能加载 SQLite。如果其中一步报错，请把版本和错误类型交给维护者，等环境确认后再安装。[已验证环境](../guides/install-macos.md)

```sh
sw_vers
python3 --version
python3 -c 'import sqlite3; print(sqlite3.sqlite_version)'
```

## 端口已被占用怎么办？

在程序目录使用安装时选定的两个路径变量，运行下方启动命令。省略端口时程序会选择一个本机端口。打开本次终端打印的地址，其他程序可以继续运行。[启动脚本](../../scripts/start_trial.py) · [路径设置](../../README.md#快速开始)

```sh
python3 -B scripts/start_trial.py --root "$SPACE_ROOT" --config "$TRIAL_CONFIG"
```

## Mac 提示“无法验证开发者”怎么办？

本版尚未签名或公证，计划在后续版本补齐。先核对发布来源和两层校验。只有你本人信任这份已校验的软件、并愿意承担打开未验证软件的风险时，才使用 macOS 针对**这一个项目**的放行选项。尝试打开后，前往“系统设置 → 隐私与安全性”，查看被拦项目名称并选择“仍要打开”（如果提供）。如果提示软件已损坏或含恶意软件，或没有对应选项，请停止并反馈。保持系统安全保护开启。[本版限制](../../README.md#已知问题) · [Apple 关于打开未公证软件的说明](https://support.apple.com/guide/mac-help/mh40616/mac)

## 导入失败怎么办？

先用随包虚构表格 `data/sample-import.csv`，核对所选空间、允许的数据性质和列名。在待核对页应能看到两条记录。若原样保存同一时刻的两条记录，会返回 `DUPLICATE_KEY_IN_BATCH`，不会写入。要练习保存、更正和撤回，请按[试用任务](trial-tasks.md)生成有两个时刻的虚构副本再导入。化验单请用已标明项目、结果和单位的清晰图片或 PDF，对照原件逐项核对。若保存结果不明确，请先查看列表和历史，再决定下一步。反馈时只提交用虚构样例重现的步骤。[首次导入](../guides/first-run.md) · [识别故障排查](../OCR-FAQ.md)

## Oura 授权没有完成怎么办？

在虚构试用空间，Oura 页只提供接入说明。若你选择接入真实账号，在单独建立、接受真实数据的个人空间打开 Oura，核对目标空间和厂商地址，再查看设备接入提示词。本人核对开发者应用登记的回调地址与本次 PTDS 安装提供的地址一致，在终端配置该实例的密钥，再自行在浏览器完成授权。返回页面后查看连接状态与最近同步时间。请勿把密钥、授权链接或回调地址栏截图交给 Agent。[Oura 设置](../guides/oura.md) · [状态显示](../../app/device_links.py)

## 怎样切换语言？

点击页头的地球，选择 English、简体中文或跟随系统。首开时也可直接选择。浏览器允许本地存储时会记住偏好。[首开指南](../guides/first-run.md) · [语言偏好](../../app/web/language_switch.js)

## 怎样删除一条数据？

在“我的数据”打开记录，核对实例、指标和日期，选择删除并确认。撤回后，这条记录从当前列表移除，旧版本仍可从历史追溯。基因文件使用单独的“删除文件”操作。想删除整个空间请看卸载说明。[版本历史](../../app/core/startorch_outbox.py) · [基因文件删除](../handbook/privacy.md)

## 怎样完全卸载？

先退出自己的 PTDS 进程，再按清单逐项列出并核对程序、数据空间、配置、凭据和本机偏好。由你本人决定删除范围，自己的源文件和备份需另行处理。[卸载与彻底删除](uninstall.md)

## 为什么英文界面里还有中文？

实例名、自建名称、来源描述、原始文件名和历史记录正文保留原文。部分尚未识别的系统模板也可能显示中文。若固定按钮或标题出现中文，可以用虚构空间重现并反馈。[已知问题](../../README.md#已知问题) · [反馈指南](feedback.md)

## 我的数据加密了吗？

当前没有应用层加密。SQLite 数据库、化验单和基因原件、本地日志都可能被有文件读取权限的程序读到。Oura 凭据默认单独存放在 macOS 钥匙串。建议开启 FileVault，并妥善保护备份。[威胁模型](threat-model.md)
