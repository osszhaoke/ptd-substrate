# 试用反馈

普通使用问题可以提交公开 Issue。若问题可能让人读到他人的数据、凭据或越过访问限制，请直接走[私下漏洞报告](https://github.com/osszhaoke/ptd-substrate/security/advisories/new)。[English](feedback.en.md)

## 复现并说明问题

1. 在新建的虚构空间用随包样例复现。记下[试用任务](trial-tasks.md)编号、界面语言和出现问题的页面。
2. 可以先从[本页附的模板](../../.github/ISSUE_TEMPLATE/trial_feedback.md)复制字段。模板并入默认分支后，再从[试用反馈表](https://github.com/osszhaoke/ptd-substrate/issues/new?template=trial_feedback.md)发起公开反馈。填写版本、Mac 型号与芯片、macOS 和 Python 版本。接着写出别人可以照做的最少步骤。
3. 用一句话写预期，再写实际结果或错误短句。例如「任务 3，用两个时刻的练习副本，预期看到 08:00 和 08:01，核对页只有一行」。若有时才发生，注明试了几次、出现几次。

## 分享截图前

优先截取虚构空间的单个界面。裁掉其他窗口、地址栏的私人参数和通知。用不透明色块盖住姓名、个人路径、实例标识、账号以及健康或基因内容。导出处理后的图片，重新打开检查，再作为附件。请勿附数据库、配置文件、凭据、真实报告或原始健康数据。安全问题的详细规则见[安全报告](../../SECURITY.md)。

## 提交之后

维护者会尽力回复，不承诺固定时限。可以在原 Issue 补充新复现步骤或说明问题已经消失。若后来发现可能涉及安全问题，后续细节请通过私下渠道发送。
