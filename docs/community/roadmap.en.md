# Roadmap draft

[Read in Chinese](roadmap.md)

These priorities are open for discussion. They may change and are not release commitments.

## Proposed for the next version

| Item | What it means for you |
| --- | --- |
| Signing and notarization | It should be easier to check who supplied the software you download. |
| More English text | When you select English, more messages from the app should use English while your own words stay as entered. |
| Local encryption (under review) | If adopted, it would give the health files on your computer an extra layer of protection. |
| Waiting with larger data sets | The aim is to shorten the wait when you save a batch or first open My data. |

## Planned

| Item | What it means for you |
| --- | --- |
| Oura | This version offers an optional personal connection so you can check sync results after you set it up and grant access. |
| Garmin | You can check the installation requirements now. A personal connection is proposed. |
| Whoop | You can check what comes with the app now. Personal setup from the device page is proposed. |
| Windows | We would like you to be able to use your own data space on a Windows computer. |
| Backup and recovery | We would like you to be able to restore your space after a mistake or a move to another computer. |
| Export and transfer | CSV is the first format to consider for taking data with you, with the FHIR health data exchange format under consideration for later. |
| Accessibility | The aim is for you to complete common tasks with a screen reader and a keyboard. |

## Exploring

| Item | What it means for you |
| --- | --- |
| Genetic data and open-source algorithms | We are exploring ways to organize and display genetic data on your device, with disease risk interpretation outside the scope. |
| Body models from phone photos | We are exploring personal models that process photos on your device, keep the photos there and have no diagnostic use. |

See the [README](../../README.en.md#known-issues) for current capabilities and measurements with fictional data. Genetic imports and lab report recognition were checked with fictional samples.
