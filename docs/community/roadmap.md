# 路线图（草案）

[English](roadmap.en.md)

这些是供伙伴讨论的优先级，档位可能调整，不代表交付承诺。

## 拟列入下一版

| 项目 | 对你意味着什么 |
| --- | --- |
| 签名与公证 | 安装时，你可以更容易核验下载的软件来自谁。 |
| 完善英文 | 切到 English 后，更多由程序生成的说明会跟随你的语言，个人输入保留原文。 |
| 本地加密（待定） | 如果采用，你保存在电脑上的健康文件将多一层保护。 |
| 大数据量下的等待时间 | 改进的目标是让你在保存一批数据或首次打开“我的数据”时少等一些。 |

## 计划中

| 项目 | 对你意味着什么 |
| --- | --- |
| Oura | 本版已提供可选个人接入，你自行配置并授权后可查看同步结果。 |
| Garmin | 目前只能检查安装条件，以后希望能在本机接入本人的数据。 |
| Whoop | 目前只能检查随包能力，以后希望能从设备页完成本人接入。 |
| Windows | 未来希望让你也能在 Windows 电脑上使用自己的数据空间。 |
| 备份与恢复 | 未来希望让你能在更换电脑或误操作后恢复自己的空间。 |
| 导出与迁移 | 优先考虑用 CSV 带走数据，长期再评估是否支持 FHIR 健康数据交换格式。 |
| 无障碍 | 希望你能用读屏软件和键盘完成主要操作。 |

## 探索中

| 项目 | 对你意味着什么 |
| --- | --- |
| 基因数据与开源算法 | 探索如何在本机整理和展示基因数据，疾病风险解读不在范围内。 |
| 用手机照片建立人体模型 | 探索在设备上处理照片、建立个人模型的方式，照片留在设备上，模型不用于诊断。 |

本版能力和虚构数据实测见 [README](../../README.md#已知问题)。基因导入与化验单识别的验证使用了虚构样例。
