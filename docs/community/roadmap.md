# 路线图

[English](roadmap.en.md)

维护者已确定下一版的四项工作重点，具体交付范围和时间可能调整。计划中的项目已确定方向，尚未排期。探索中的想法可能不会发布。

## 下一版（在做）

| 优先项 | 对你意味着什么 |
| --- | --- |
| 签名与公证 | 目标是让你的 Mac 在首次打开 PTDS 时识别软件的发布者。 |
| 本地加密 | 目标是让拿到文件副本的人难以读取你保存在 Mac 上的健康数据。 |
| 完善英文 | 选择英文后，更多由程序生成的提示会跟随语言切换，你填写的原文照常保留。 |
| 加快保存和打开 | 目标是在记录较多时，缩短整批保存和打开“我的数据”的等待。 |

alpha.2 的健康数据库、已保存的化验单、基因文件和本地日志均无应用层加密。在 Mac 上配置 Oura 时，凭据默认存入钥匙串。下一版拟用钥匙串保管数据加密密钥。哪些文件和备份会加密、失去密钥后能否恢复以及如何恢复，仍待设计确定。[当前存储与保护范围](threat-model.md)

## 计划中

| 项目 | 对你意味着什么 |
| --- | --- |
| Oura | 个人空间支持本人配置和授权，后续计划简化配置；试用版使用虚构数据验证。 |
| Garmin | 现在可做只读接入检查，个人账号接入已列入计划。 |
| Whoop | 现在可做只读接入检查，个人账号接入已列入计划。 |
| Windows | 计划让你也能在 Windows 电脑上使用自己的数据空间。 |
| 备份与恢复 | 计划让你在误操作或更换电脑后更容易恢复原有空间。 |
| 导出与迁移 | 计划让你一键导出 CSV、带走数据，长期再考虑 FHIR 格式。 |
| 无障碍 | 计划让你能更顺畅地用读屏软件或键盘完成主要操作。 |
