| 情形 | 本版措施 | 依据 |
|---|---|---|
| 导入错空间或误保存 | 安装时选择接收空间。伙伴路由核对目标。表格与化验单先显示候选，化验单逐行确认，保存后保留来源关系。CSV 练习可用自己保留的副本核对原文。 | [目标校验](../../app/trial_target.py) · [确认流程](../../app/partner_ocr.py) · [来源读取](../../app/evidence_navigation.py) |
| 网络上的其他设备尝试访问 | 伙伴服务绑定本机回环地址。按许可开放路由，本地写请求要通过请求检查。 | [服务入口](../../app/server.py) · [请求检查](../../app/trial_target.py) |
| 意外对外传输 | 默认安装关闭第三方设备接入。Oura 需要配置且由本人授权，在匹配的数据空间使用。服务地址可以覆盖，授权前应核对厂商地址和本机回调。 | [安装器](../../app/tools/partner_trial_setup.py) · [Oura 接入](../guides/oura.md) |
| 把凭据夹进数据或反馈 | 在 macOS 默认配置中，Oura 使用系统钥匙串，服务名为 `ptds-oura`，账户按实例区分。显式选择文件存储时，应用按仅当前用户可访问的权限创建新目录和新文件，凭据为明文。原有目录或文件即使权限过宽，覆盖时也不会自动收紧。请核对已有存储仅本人可读。 | [凭据存储](../../app/oura.py) · [安全报告](../../SECURITY.md) |

## 未加密的数据

**当前没有应用层加密。** 选定空间的两个主库为普通 SQLite。化验单保存时保留原始字节，识别记录单独保存。基因原件按原样存储，位点索引使用 SQLite。事件日志和基因接收回执是可读文本。文件权限、文件指纹和数据库事务均不替代加密。建议通过“系统设置 → 隐私与安全性 → FileVault”开启磁盘加密，并单独保护备份。[主库存储](../../app/core/sqlite_util.py) · [化验单原件](../../app/partner_ocr.py) · [基因原件与回执](../../app/gene_assets.py) · [位点库](../../app/gene_db.py) · [事件日志](../../app/server.py)

## 本机与第三方的边界

已入侵的电脑、可读取这些文件的本机程序，或能使用已解锁账户的人，都可能接触健康记录。FileVault 保护静置磁盘。它不能阻止已登录会话中有权限的程序读取文件。PTDS 也不能控制你在厂商账户中已经保存的数据、自己导出的副本或独立备份。使用共享 Mac 时，请锁屏并使用单独账户。[本机数据说明](../handbook/privacy.md) · [删除与卸载](uninstall.md)
