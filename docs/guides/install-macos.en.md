# Install on macOS

[简体中文](install-macos.md)


## Requirements
Verified on Apple silicon with macOS 27.0.1 and Python 3.14.8. Prepare a new space directory and a terminal.

## Install
Follow the [installation protocol](../../AGENT_INSTALL.en.md). Start in a new directory and use a regular account. Allow room for the app, original files and local databases.
