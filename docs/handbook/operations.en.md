## Scope
Stop the foreground process with Ctrl+C and keep the chosen directory. Reopen it with the same --root and --config. Corrections append a version. Deleting an observation withdraws that record from the current list and preserves history. After a clean shutdown, back up the entire space. Avoid copying a single active database file.

## Try a fictional genetic file

Use app/fixtures/fictional-genotype-sample.txt. Choose Synthetic for its data type. Look up rs9100000001, check coverage, then remove the file from the same space. This sample is generated and represents no person.
