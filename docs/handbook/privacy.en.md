# Privacy and network use

[简体中文](privacy.md)


## Scope
The default installation uses loopback. Pages and fonts ship with the app. Oura is an optional account channel; enabling it uses provider servers. Check the target and scope first. Keep all instances, secrets, logs and databases outside public repositories.

## Genetic files on this Mac

The selected space stores the original file, properties and locus index under startorch/gene. Open My sources, then Files and reports and Genetic sequencing data. The page is titled Raw genetic files. Choose Delete file under the file name and confirm. Copies with identical content in this space are removed together. Other files and spaces are preserved. Removing the last indexed file also removes the index. Deletion covers the application-managed copy. The source you selected and separate backups, including Time Machine snapshots, are outside this operation. Coverage checks inspect the local file only.
