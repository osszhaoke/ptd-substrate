# 隐私与网络

[English](privacy.en.md)


## 使用边界
首次安装后默认走回环。网页和字体随包提供。Oura 为可选账号通道，启用后使用厂商服务器；接入前先核对目标和授权范围。不要把任何实例、密钥、日志或数据库放进公开仓库。

## 基因原始文件的存放与删除

原件、属性和位点库保存在所选数据空间的 startorch/gene 下。在“我的数源 → 来自文件报告 → 基因测序数据”找到文件，选择“删除文件”并确认。同一空间内容相同的副本一并删除，其他文件和空间保留。最后一份已建索引文件删除后，位点库也会删除。删除范围是程序管理的副本；自己选取的源文件和独立备份（含时间机器快照）不在此操作范围。覆盖核对只在本机进行。
